# NEXUS V1.0 使用指南

开发者：竖 · 邮箱：1564898589@qq.com · 版本 1.0.0 · 纯本地 Windows 桌面应用

NEXUS 是英雄联盟智能战术终端：OP.GG 韩服真实统计 + 本机客户端只读情报 + 规则/AI 战术分析。
所有数据存储在本地，不上传战绩、不读取游戏内存、不截屏、不自动操作游戏。

---

## 1. 安装与启动

1. 运行 `NEXUS Setup 1.0.0.exe`，按提示安装（无需管理员权限）。
2. 启动 NEXUS。首次启动会弹出 V1.0 版本公告（开发者：竖），阅读后确认即可。
3. 内置种子数据：173 位英雄完整资料 + OP.GG 韩服 16.23.1 版本统计，开箱即用。
4. 卸载时默认**保留**你的数据库、备份与设置（位于 `%APPDATA%/nexus-lol-tactical`）。

## 2. 数据来源（务必了解）

| 来源 | 内容 | 标注 |
|---|---|---|
| OP.GG 韩服 | 胜率/登场/禁用/Counter/出装/符文（翡翠+） | 每条含版本/段位/样本/采集时间 |
| Riot Data Dragon | 中文英雄/技能/装备/符文/原画 | 官方公开静态库 |
| 本机客户端 LCU/SGP | 你的国服战绩、选人阶段十人信息 | 需启动并登录国服客户端 |
| 启发式分析 | 阵容/对线/评级推理 | 明确标「启发式」，与真实统计分离 |

- 统计只有韩服一个服务器，**不与国服混用**；界面始终显示当前筛选。
- 未连接客户端时，战绩/情报功能如实显示「不可用」，绝不显示假数据。
- OP.GG 解析属非官方用途，仅供个人学习研究；来源失效时保留旧数据。

## 3. 国服战绩查询（玩家战绩中心）

1. 启动并登录国服英雄联盟客户端（WeGame 启动亦可）。
2. 侧栏「国服情报 → 玩家战绩中心」，顶部会显示连接状态。
3. 输入召唤师名称搜索 → 查看资料卡、段位、S/A/B/C/D 评级。
4. 选择 10/20/50 场查询历史战绩；数据缓存到本地，之后离线可看。
5. 「设为自己」后，复盘/成长/实时教练默认分析你的账号。
6. 收藏玩家、标记重点关注/威胁（情报室与提醒会用到）。

> 评级说明：长期实力（缓存总样本）与近期状态（近 10 场）分开计算；
> 样本 <3 场不评级；绝活英雄 = ≥5 场且胜率 ≥55%。评级是相对表现，不是永久标签。

## 4. 对局情报室 + 实时教练 + NEXUS LIVE

- 进入英雄选择后，NEXUS 自动列出双方十人并关联缓存战绩与评级。
- 「生成侦察报告」输出 PRE-MATCH SCOUTING REPORT：事实/推断/建议三标记。
- 点击任意玩家打开快速情报卡：评级依据、绝活、当前英雄表现、威胁标记。
- 「实时教练」按阶段工作：选人期给符文/技能/对位建议；对局中回顾赛前计划。
  **对局内实时经济/位置等数据不可用**——这是合规边界（不读内存/不截屏），不是缺陷。
- 顶栏眼睛按钮或 **F9** 打开 NEXUS LIVE 悬浮窗：置顶、拖动顶栏移动、滑杆调透明度、
  边缘拉伸调整大小，位置与透明度自动记忆。

## 5. 情报提醒

选人阶段自动检测（本地计算）：
- 你标记的玩家出现在敌方；
- 敌方选出其绝活英雄（基于缓存真实战绩）；
- 你的绝活英雄被对方禁用。

提醒以弹窗 + 情报室列表呈现，侧栏情报室显示未读角标。设置中可逐项开关。

## 6. 赛后复盘 + 个人成长 + 版本趋势

- **赛后复盘**：选择账号 → 点击任意缓存对局 → 逐场事实/推断/建议，与你的个人基准对比。
- **个人成长**：近期 vs 此前胜率/KDA/死亡趋势、胜负走势条、英雄池演变。需 ≥6 场缓存。
- **版本趋势**：当前版本强度分布、胜率/登场/禁用榜（样本 ≥200 场门槛）。
  跨版本趋势需多版本数据积累，每次「更新数据」记录当时版本。
- 以上每页都有「AI 战术分析（可选）」：未配置模型时显示**规则分析**并明确标记，不冒充 AI。

## 7. AI 模型中心（可选，永不强制）

1. 侧栏「系统 → AI 模型中心」，添加 OpenAI 兼容服务商（Base URL / API Key / 模型名）。
2. API Key 用 Windows DPAPI 加密存储，不写入日志、不进入模型上下文。
3. 「测试连接」验证；按任务（查询/BP/复盘/实时/战术）路由到不同模型。
4. 调用日志显示**实际调用的模型**；主模型失败自动备用，降级时明确标记「规则分析」。
5. 隐私开关控制发送范围；LCU Token、密码、密钥、无关本地文件永不发送。

## 8. 数据中枢

- 状态总览：条目数/完整性/版本/采集时间。
- 手动/自动备份；恢复前自动快照，可回滚。
- 质量检查：来源缺失/样本异常/重复/混服检测。
- 采集日志与运行日志可导出（日志不含密码/令牌）。

## 10. 常见问题

- **连不上客户端？** 确认客户端已启动并登录；LCU 页点「立即连接」；看端点可用性逐项结果。
- **战绩查询为空？** 需登录国服客户端；私密战绩无法查询；SGP 深分页不可用时自动回退 LCU 首页并提示。
- **评级是 ?** 样本不足或身份未确认，先查询战绩缓存。
- **悬浮窗不见了？** 按 F9 或顶栏眼睛按钮重新打开。
- **数据更新失败？** 保留原有数据，查看数据中枢日志；网络受限时可稍后重试。
