# 夸克网盘镜像接入指南（未来发布时按此操作）

**现在不需要做任何事。** 夸克渠道的配置与调用框架已开发完成并实测；未配置时显示「尚未配置 · 等待接入」。

## 一、关键结论（已实测验证，务必理解）

夸克分享链接**不是**可供程序自动下载的直链：
- 分享页下载需要用户登录会话与限时签名 URL，无稳定、合法、免人工的自动下载接口；
- 任何「自动下载夸克」的实现都意味着模拟登录/破解接口/绕过验证码——**本项目明确禁止**。

因此夸克渠道的正确形态是**人工镜像 + 自动校验**：
1. 应用内展示分享链接与提取码（一键打开分享页）；
2. 指引明确告知要下载的文件名、版本号、官方 SHA-256；
3. 用户手动下载后，点击「选择本地安装包」；
4. NEXUS 自动做 SHA-256 + 文件大小 + Authenticode 签名三重校验，通过才允许安装；
5. 校验失败一律删除拒装。备用方式：任意来源的同版本文件都可走此校验入口。

## 二、目录结构（上传时遵守，历史永不覆盖）

```
NEXUS/
├─ Releases/
│  ├─ v1.0.0/   NEXUS Setup 1.0.0.exe + .sha256 + nexus-update.json
│  ├─ v1.1.0/   …（每个版本独立目录，永久保留）
│  └─ …
├─ Latest/      仅最新正式版的三个文件（与 GitHub Release 逐字节一致）
└─ Archive/     更早版本归档（可选）
```

规则：
- **同一版本的安装包必须与 GitHub Release 资产完全相同（同一 SHA-256）**，严禁在两个平台分别构建出不同文件；
- 新版本只新增目录与更新 Latest，绝不覆盖或删除历史版本；
- 每个版本目录放三个文件：安装包、`<安装包>.sha256`、`nexus-update.json`（来自 `release/channel/`，由发布流水线生成）。

## 三、上传步骤（你本人操作，AI 协助整理）

1. 登录夸克网盘，创建 `NEXUS` 目录及上述结构。
2. 运行 `node tools/release-prep.cjs` 生成 `release/quark-upload-manifest.json`——里面列明本次要上传的文件、源路径、SHA-256、目标目录。
3. 按清单上传（网页拖拽即可）。
4. 对 `Latest` 目录（或单文件）创建分享，获取分享链接与提取码（建议永久有效）。
5. 验证分享可用：无痕浏览器打开链接 → 输入提取码 → 能下载且文件 SHA-256 与清单一致。
6. 回填两处：
   - 应用内「版本更新 → 渠道配置 → 夸克分享链接 / 提取码」→ 保存；
   - `release/quark-upload-manifest.json` 的 `share` 字段留档。
7. 国内下载流程验证：应用内触发夸克渠道 → 打开分享页 → 下载 → 选择本地文件 → 校验通过。

## 四、客户端如何消费夸克（已实现）

- 智能选择：GitHub 测速不达标或下载失败且开启自动切换 → 转夸克人工指引；
- 指引携带：分享链接、提取码、对应版本号、安装包名、官方 SHA-256、下载状态（需人工）、备用方式（本地文件校验）；
- 用户选择的文件走与在线下载完全相同的安全链；
- 夸克未配置时不会假装可用，自动落回本地兜底或保留当前版本。
